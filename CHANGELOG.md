# Changelog

Versions of `skills/us-import-risk-screen` (the plugin `plaudeapi-trade` carries the same number). The version is bumped on every rule or pin change. Replay results are in `conformance/RUNS.md`.

## 0.5.0 — 2026-11-16
- Standards alignment, no rule change. `SKILL.md` frontmatter gains `license: MIT` and `metadata` (`version`, `author`, `last-primary-source-review`, `revalidate-by`); `description` now begins "Use this skill when…".
- The production alignment pin and the maintainer notes moved to `references/ALIGNMENT.md`; the skill body is shorter (an estimated 4,900 tokens, character count divided by four; no tokenizer was available). The version history moved here.
- Added `evals/` in the `claude plugin eval` format (26 conformance cases and 20 trigger tests, generated by `scripts/gen_evals.py` from `conformance/cases.yaml` and `conformance/triggers.yaml`), `.claude-plugin/marketplace.json`, `AGENTS.md`, `SECURITY.md`, `agents/openai.yaml` (Codex display metadata), three example prompts in the README, and the release tag scheme `plaudeapi-trade--v<version>`.
- `VERIFY.md`: paths follow the move; new Tier 1f (five version strings agree, including `plugin.json`) and 1g (evals match the fixtures).
- Added `mcp/`, an optional separately installed read-only public-facts MCP server (versioned 0.1.0, own tests). The plugin does not load it and registers no MCP server; it is not published to PyPI or the MCP registry.
